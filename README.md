# GSL Interiors Website

Professional responsive website source and production build for GSL Interiors.

## Deployment

The production-ready static site is in the `dist/` directory in the supplied project ZIP. For Cloudflare Pages, connect this repository and set the build output directory to `dist`. If using the included Python build script, set the build command to `python3 build.py` and output directory to `dist`.

## Before publishing

- Add verified phone, WhatsApp, email and business address in `src/config.js`.
- Replace decorative project visuals with genuine owner-provided or properly licensed interior photographs.
- Review the Privacy Policy and Terms pages.
- Deploy a preview first and test the contact form and calculator before connecting any production domain.

Existing live websites should not be replaced without owner approval.
